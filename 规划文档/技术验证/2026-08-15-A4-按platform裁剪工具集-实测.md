## 结论：✅ 支持按 platform 精细裁剪工具集（可开工）

**证据链（源码级实锤）**：

1. **平台注册表**（`hermes_cli/platforms.py:42`）：`api_server` 是注册平台，默认工具集 `hermes-api-server`。
2. **运行时解析**（`gateway/platforms/api_server.py:1246-1251`，`_create_agent` docstring 原文）：
   > Toolsets are resolved from config.yaml **platform_toolsets.api_server** (same as all other gateway platforms), falling back to the hermes-api-server default.
3. **白名单语义**（`hermes_cli/tools_config.py:_get_platform_tools`）：`platform_toolsets.<platform>` 为显式工具集名单时按 direct membership 生效；未配置才回退平台默认。
4. **隔离性**：`platform_toolsets` 是「platform → toolsets 列表」映射，写 `api_server` 键**只影响 API Server 通道**，`weixin` / `cli` 键互不干扰（当前 config.yaml 仅定义了 `cli` 键）。

**裁剪方案（Spec A4 保留清单 → 工具集名映射）**：

```yaml
platform_toolsets:
  api_server:
    - memory          # 记忆（核心）
    - skills          # 技能（核心）
    - session_search  # 查历史
    - web             # 只读查询类（web_search 等）
  # cli / weixin 键不动 —— 微信与 CLI 工具集完全不受影响
```

被裁掉的重工具（terminal/file/browser/delegation/cronjob/code_execution/computer_use 等）在 api_server 通道不出现，满足「语音误触危险操作」防护。

## API Server 启用参数（实查 config.py:4283-4325）

| 配置项 | 作用 | 值 |
|---|---|---|
| `API_SERVER_ENABLED` | 启用 OpenAI 兼容 API Server | `true` |
| `API_SERVER_KEY` | Bearer 鉴权（不设则拒绝启动） | 需生成强密钥 |
| `API_SERVER_PORT` | 端口 | `8780`（默认 8642 落在 Windows 排除端口段 8605-8704，绑不上 → 改 8780） |
| `API_SERVER_HOST` | 绑定地址 | `127.0.0.1`（默认，loopback 也必须配 key） |
| `API_SERVER_MODEL_NAME` | /v1/models 对外模型名 | 默认 `hermes-agent` |

鉴权实查（`gateway/platforms/api_server.py:853`）：`Authorization: Bearer <API_SERVER_KEY>`，hmac.compare_digest 比对；无 key 时 server 拒绝启动。

## 影响面评估

- 启用 API Server + 写 `platform_toolsets.api_server` 均为**新增配置**，不改动 weixin/cli 现有键。
- **需重启 gateway 生效**（配置运行时读取点为 agent 创建时，但平台注册在 gateway 启动时）→ 重启会短暂中断微信 bot（秒级）。
- API Server 与微信共用同一 profile → persistent memory 天然共享（满足 v0.3 核心验收「与微信共用记忆」的架构前提）。
