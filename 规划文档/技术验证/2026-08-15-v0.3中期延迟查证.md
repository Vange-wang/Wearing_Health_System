## 结论（先给答案）

**中期「轻量直通」方案在当前 Hermes 0.18.2 上无法落地**——API Server 不暴露任何 per-request 轻量模式 / 记忆跳过 / 工具集覆盖开关。三条查证结论均为「不支持」或「无内置机制」。

| # | 查证项 | 结论 | 关键证据 |
|---|---|---|---|
| 1 | 只注入 memory、跳过 skills/工具 的轻量模式 | ❌ **不支持**（API server 无此开关） | `_create_agent`（api_server.py:1345）工具集 = `platform_toolsets.api_server` 静态解析，无 per-request 覆盖；`tools`/`tool_choice` 请求字段仅用于 Idempotency-Key 指纹（:2306），不控制 agent 工具 |
| 2 | agent 预热/复用机制 | ❌ **无复用**，每请求新建 AIAgent | api_server.py:5 声明「stateless」；每请求 `_create_agent` 重建（含记忆检索 + skills 预加载 + 规则注入），2.4s 开销每请求付 |
| 3 | 冷启动 47.5s 是否可预热 | ⚠️ **无 gateway 级预热**；仅可外部「空请求暖机」 | 无 warmup/prewarm 代码；冷启动 = 首个请求触发全量初始化 |

## 查证详情

### #1 轻量直通（只注入 memory，跳过 skills/工具）—— 不支持

- **工具集解析**（api_server.py:1337）：`enabled_toolsets = _get_platform_tools(user_config, "api_server")` —— 从 `platform_toolsets.api_server` **静态**读取，请求体内无法覆盖。
- **请求体 `tools`/`tool_choice`**（:2306）：仅参与 `_make_request_fingerprint`（幂等去重键），**不传给 agent**，起不到"禁用工具"作用。
- **记忆注入**：AIAgent 存在 `skip_memory`/`skip_context_files` 参数（main.py:2342 `--ignore-rules` 用），但 API server 的 `_create_agent` **未暴露**这两个开关——即 API 层无法"跳过规则/记忆/预加载技能"。
- **唯一近似**：静态把 `platform_toolsets.api_server` 裁到只剩 memory（去掉 skills/web）。但这是**平台级全局**，与 A3/A4「共用记忆 + 技能可用」冲突，且无法 per-request 路由（快路径/慢路径分流做不了）。

### #2 agent 预热/复用 —— 无

- api_server.py 模块 docstring 明示「stateless」；`_create_agent` 每个请求 `AIAgent(...)` 全新实例，无对象池/复用/缓存。
- 结论：2.4s 启动开销是 per-request 固定成本，无法靠复用摊销。

### #3 冷启动预热 —— 无内置，仅外部暖机

- 无 gateway 启动预热 / warmup / preload 代码。
- 42s 冷启动 = 首个请求触发 AIAgent 全量初始化（模型加载 + 记忆 provider 建立 + skills 预加载 + 规则注入）。
- **可操作的缓解**：gateway 启动后由外部发一个空/占位请求暖机（一次性 42s，之后稳态 ~3.1s），属"运维手段"非 Hermes 内置。

## 对三期方案的影响与建议

1. **短期（安抚语）**：已实现（v0.3 收尾，T9 过），不受本查证影响，照常推进。
2. **中期（轻量直通）**：**受阻**。根因是 Hermes API server 未开放 per-request 轻量开关。两条出路：
   - (a) 等 Hermes 侧加能力（在 `_create_agent` 暴露 `skip_memory`/工具集覆盖/轻量 mode，或新增 `X-Hermes-Lightweight` 头）；
   - (b) **绕开 Hermes agent，直接走长期方案**：voice-bridge 内置 RAG + 裸模型（记忆仍只读共享 Hermes 那份）。
3. **长期（知识库 RAG）**：反而成为当前唯一能真正把延迟压回 ~1.5s 的可行路径，建议**提前立项**评估（voice-bridge 侧裸模型直连 + 本地向量检索，不依赖 Hermes 改版）。

**建议 Hermes 裁决**：中期轻量直通是否（a）提交 Hermes 侧能力需求，或（b）直接跳到长期 RAG 方案。
