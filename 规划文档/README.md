# 规划文档

本目录承载项目的"要做什么、为什么、怎么做"：决策、选型、规格与阶段计划。

## 阅读顺序（新成员/几周后的自己，按此顺序）

1. `Hermes语音开发板实现方案-20260811.docx` — 总纲：愿景、架构、已敲定决策（v1.1，第二节 14 条）
2. `技术验证/` — 选型决策记录（ASR/TTS 引擎、延迟预算）
3. `Spec文档/` — 执行级开发规格（开发环境验证 → 语音桥 → 后续固件）
4. `里程碑文档/` — 阶段交付计划与进度跟踪（M0 → M1 → M2）

## 子目录职责

| 目录 | 职责 | 命名规范 |
|---|---|---|
| `Spec文档/` | 功能/任务规格（本仓库最高裁决） | `YYYY-MM-DD-功能名-spec.md` |
| `技术验证/` | 选型结论与风险记录 | `YYYY-MM-DD-主题-结论.md` |
| `里程碑文档/` | 阶段计划、准入条件与 DoD | `README.md` + 阶段记录 |

## 变更纪律

- Spec 变更须 Hermes 确认；Spec 未覆盖的需求先补 Spec 再开发（见 `../AGENTS.md`）
- 决策敲定后更新实现方案（docx）第二节记录区，并同步本目录相关文档
