> 关联文档：实现方案 v1.1（规划文档/根）、开发环境验证 spec v0.1、语音桥 spec v0.1、agent.md。

## 0. 角色分工（红线）

| 角色 | 职责 | 强制模型 |
|---|---|---|
| WorkBuddy | 一切开发/验证执行：工具链安装、示例编译烧录、固件代码、语音桥代码、自测 | **Kimi K3** |
| Hermes | 规划、Spec、审核、验收、放行（**不写业务代码**） | deepseek-v4-pro（产出/审查时） |

## 1. 三条并行线（到货前即启动）

```
线A 电脑侧（不依赖硬件，立即开工）
    ① 语音桥服务开发（按语音桥 spec v0.1，WorkBuddy/K3）
    ② ESP-IDF v5.2.1 工具链安装（~2GB，到货前装完，D 盘）
    ③ sherpa-onnx + SenseVoice 模型下载（models/）
线B 板子侧（依赖硬件）
    M0 环境验证 → M1 固件开发（本文档 §3/§4）
线C 流程侧
    Hermes 审核 gate + 里程碑推进
汇合点：联调（板子 ↔ 语音桥 ↔ DeepSeek）
```

## 2. 到货当天（WorkBuddy，0.5h）

1. 开箱核对：蓝色标准版 + SENSOR/DOCK/BRACKET/BREAD 四配件齐全、屏幕无损伤
2. 首次上电：USB-C 接电脑，跑**出厂固件**体验官方唤醒词+命令词 demo（建立目标体验基线）
3. 串口确认：设备管理器识别 COM 口，日志正常
4. 异常 → 立即回报 Hermes（拍照/日志）

## 3. M0 开发环境验证（1~2 天，WorkBuddy/K3 执行）

- 按 `Spec文档/2026-08-11-开发环境验证-spec-v0.1.md` 的 V-01~V-12 顺序执行
- 顺序：V-01 工具链 → V-02 BSP 识别 → V-03 LCD/触摸 → V-04 双麦 → V-05 喇叭 → **V-06 chatgpt_demo 全链路（核心关）** → V-07 WiFi → V-08 PSRAM → V-09 opus → V-10 BLE → V-11 烧录 → V-12 ESP-SR
- 证据存 `Code文档/v0.1-环境验证/`（每条：截图/日志/耗时）
- 产出 `环境验证报告-v0.1.md` → Hermes（v4-pro）审核
- **M0 gate**：V-01~V-12 全绿 + 报告审核通过 → 锁定工具链（预期 ESP-IDF v5.2.1）→ 才可开固件开发

## 4. M1 固件开发（M0 gate 通过后，WorkBuddy/K3）

| 步骤 | 内容 | 依赖 |
|---|---|---|
| F1 | 固件 v0.1（按键说话版）：录音 → 按键判定 → opus 编码 → WiFi 上传 → 接收音频 → I2S 播放 → 屏幕状态显示 | M0 gate |
| F2 | 联调：板子 ↔ 语音桥 ↔ DeepSeek；延迟打点实测（X-Timing），逐环节定位超预算点 | F1 + 线A 语音桥 |
| F3 | 唤醒词第二步：ESP-SR 预制中文唤醒词（与 F2 并行跟进） | F1 |
| F4 | 自定义唤醒词训练（最后，不阻塞主线） | F3 |

- 固件代码由 WorkBuddy 编写，Hermes 审查（至多 3 轮，审查报告落 `协同工作文档/审查报告/`）
- **M1 前置决策**：联调前必须先定 opus 线协议（编码参数/分帧/Content-Type/服务端解码责任），见 v0.2 Spec §2 留白（A2 裁决）
- **M1 gate**：联调 3 项全绿（语音链路通 / 真机端到端开口延迟实测 / 手机热点无线）→ 才可进 M2 阶段2 迁移
  - 注：原"共用记忆"已移出 M1，属 v0.3/Hermes 会话集成（2026-08-14 Vange 裁决 D）

## 5. 风险预案

| 风险 | 预案 |
|---|---|
| 某外设示例跑不通 | ESP Launchpad 刷官方固件交叉验证——判别硬件问题 vs 代码问题 |
| 延迟超 1.5s | 打点定位，重点查 LLM 首字 + TTS 分句流水线（流式化） |
| opus 内存/性能问题 | 16MB PSRAM 兜底；降采样/小模型备选 |
| 固件刷坏 | 分区表保留 factory 固件，随时回刷 |
| 工具链下载慢 | 离线安装包/镜像；D 盘安装 |

## 6. 协作纪律（agent.md 全量适用）

- 每步执行回报格式：`[状态] 一句话结论 + 证据路径`
- 任务单缺项不接；DoD 前置确认；Spec 未覆盖先补 Spec
- WorkBuddy 开发必须 Kimi K3；Hermes 审查必须 deepseek-v4-pro
- 阻塞 15 分钟无响应 → 重发并 @Vange
