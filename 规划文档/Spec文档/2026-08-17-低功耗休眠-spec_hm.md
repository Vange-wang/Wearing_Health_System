# 低功耗休眠与按键唤醒 Spec

- **起草**：Hermes（deepseek-v4-pro）· 2026-08-17
- **依据**：`2026-08-17-低功耗休眠-方案对齐_wb.md`（WorkBuddy 整理，Vange 拍板三项决策）
- **实施**：WorkBuddy（固件 voice_agent.c）

---

## 1. 目标

设备空闲 3 分钟无互动 → 自动进入浅睡（Light Sleep）省电；按键呼叫（顶部圆键 / MUTE）毫秒级唤醒并恢复正常语音交互。为将来电池供电（ISSUE-0005）做功耗储备。

## 2. 需求（Vange 已拍板）

1. 空闲 **3 分钟**无互动 → **Light Sleep（浅睡）**。
2. **按键唤醒**：顶部圆键（GPIO0）或 MUTE 键（GPIO1），任一按下即醒。
3. **未来扩展预留**：唤醒词自动呼叫（本期不做，但方案不堵死这条路——选 Light sleep 而非 Deep sleep 即为此）。
4. 目标：为电池供电做功耗储备（本期仍 USB 供电，休眠机制先行验证）。

## 3. 休眠选型

| 模式 | 功耗 | 唤醒延迟 | 按键唤醒 | 唤醒词 | 裁决 |
|---|---|---|---|---|---|
| Modem sleep（仅关 WiFi） | ~20-30mA | 无 | — | 可 | ✗ 省电不够 |
| **Light sleep（浅睡）** | **~0.8mA** | 毫秒级 | ✅ | 可 | ✅ **选型** |
| Deep sleep（深睡） | ~10μA | ~10s（重连 WiFi） | ✅ | ❌ | ✗ 唤醒词不可用 + 重连慢 |

## 4. 详细设计（固件 voice_agent.c）

### 4.1 空闲计时

- 维护 `last_active` 时间戳，每次 `voice_round()` 返回（一次语音交互完成）时刷新。
- `talk_task` 空闲循环检查：`now - last_active > 180s` → 进入浅睡。
- **空闲判定语义**：按「最后一次语音交互完成」起算，不是按键空闲（防止长时间挂机不睡）。

### 4.2 进入浅睡（顺序）

1. 停止录音/播放，**音频 codec（ES7210/ES8311）断电**（省电；唤醒后重开）。
2. **断开 WiFi**（`esp_wifi_stop()`，省电大户，避免空耗）。
3. 配置 ext1 唤醒源：`esp_sleep_enable_ext1_wakeup(GPIO0|GPIO1, ESP_EXT1_WAKEUP_ANY_LOW)`。
4. `esp_light_sleep_start()`。

### 4.3 唤醒后恢复（顺序）

1. 重新 `esp_wifi_start()` + 连接（复用 `wifi_connect()`）。
2. 重新 `mdns_init()` + 注册服务（mDNS 需随 WiFi 重建，否则 `voicebridge.local` 解析失效）。
3. 音频 codec 重新初始化（供电 + 配置）。
4. **防抖**：忽略唤醒瞬间的按键边沿（唤醒动作不触发语音，重连完成后用户正常说话）。

### 4.4 唤醒恢复延迟目标

按键按下 → WiFi 重连 + mDNS + codec 就绪 → 可交互：**目标 ≤5s**（实测记录；3 分钟空闲后用户按键，等几秒可接受）。

## 5. 关键决策（已对齐）

| # | 决策点 | 裁决 |
|---|---|---|
| 1 | WiFi 处理 | **浅睡完全断开**（省电多），唤醒重连（~几秒）；3 分钟空闲后不需要秒级响应 |
| 2 | 音频 codec | **断电省电**，唤醒后重开（需实测重开时序，避免音频异常） |
| 3 | mDNS | 唤醒后随 WiFi **重建**（配套 WorkBuddy 的 mDNS 实现） |
| 4 | 空闲判定 | 按「最后一次语音交互完成」起算 3 分钟 |
| 5 | 防抖 | 唤醒瞬间按键排除，不触发语音 |

## 6. 验收标准

1. 设备空闲 3 分钟无交互 → 自动进入浅睡（可测电流，相对 Modem sleep 显著下降）。
2. 按顶部圆键或 MUTE → 毫秒级唤醒，WiFi 重连 + mDNS + codec 恢复后正常语音交互。
3. 唤醒后 `voicebridge.local` 可正常解析（mDNS 重建生效）。
4. **唤醒恢复延迟 ≤5s**（按键 → 可交互，实测记录）。
5. 反复「休眠 → 按键唤醒 → 对话 → 再休眠」循环稳定，无内存泄漏/卡死。

## 8. 风险

| 风险 | 缓解 |
|---|---|
| codec 断电后重开时序异常（唤醒后无声/爆音） | 实测重开时序，必要时保留供电只关 I2S 时钟 |
| WiFi 重连失败（路由器不可达） | 复用现有重连机制 + 超时提示 |
| mDNS 重建遗漏 → voicebridge.local 解析失效 | 验收 T2 覆盖 |
| 3 分钟空闲过短（用户思考中被打断） | 以「语音交互完成」起算（思考中不算空闲），3 分钟是 Vange 拍板 |
