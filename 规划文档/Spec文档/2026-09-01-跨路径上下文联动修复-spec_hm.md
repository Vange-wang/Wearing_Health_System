## 1. 用户语义（裁决）

指代追问分两类 + 降级，处理方式不同：

| 类型 | 识别 | 语义 | 处理 |
|---|---|---|---|
| **REPLAY 纯复述** | phrase-level REPLAY 复合短语（§3.1），非单字 | 要求重播上一轮小V完整回复，非重查 | **pipeline 内部 replay 执行模式**：读上一轮 reply_text 全文 → 分句 → TTS；不调 LLM、不排 HERMES comfort、零网络 |
| **CONTEXT 上下文追问** | phrase-level CONTEXT 复合短语（§3.1），非单字 | 指代上一轮内容，需 LLM 结合上下文理解 | **延续 last_route + 固定结构上下文前缀**（仅一轮、长度上限）单次调用对应 LLM（§3.3 逐路由闭合） |

**降级语义**（快照空 / 过期 TTL）：
- REPLAY 无快照 → 固定本地诚实模板 `REPLAY_NO_SNAPSHOT_TEXT`，不调任何 LLM/网络；
- CONTEXT 无快照 → 固定本地诚实模板 `CONTEXT_NO_SNAPSHOT_TEXT`，不调任何 LLM/网络。
- 裁决（S3）：无历史时两路追问都**不得**退回普通路由/慢路径，避免把「重新说一遍/刚才那个」这类无指代文本送进 LLM 做无意义慢路径调用。
- 任何降级都**不得**误答成「不知道要干什么」（ISSUE-0013 原始症状）。

固定诚实模板（本地常量，零网络/零 LLM）：
- `REPLAY_NO_SNAPSHOT_TEXT = "刚才没有可以重复的内容哦，先跟我说说话吧。"`
- `CONTEXT_NO_SNAPSHOT_TEXT = "我有点没跟上，你是指哪件事呀？"`

## 2. 状态模型（最小）

- **唯一所有者**：`StreamingPipeline`（不是 Router / LLM / LightweightLLM）。
- **最小字段**（4 项，内存 only，不落盘）：
  - `last_user_text: str`
  - `last_reply_text: str`
  - `last_route: str`（取值**仅允许** LIGHTWEIGHT / RAG / HERMES / DATA）
  - `last_ts: float`（提交时点，time.monotonic）
- **提交时点**：LLM/TTS 完整回复完成后（主流程 yield 完所有帧、`assistant_parts` 完整拼接后）才写；首帧前绝不动快照。
- **TTL**：`SNAPSHOT_TTL_SECONDS = 600`（对齐 `ROUTE_TTL_SECONDS`）；`now - last_ts > 600` 视为无快照。
- **maxlen**：仅上一轮（1 轮），不维护多轮。
- **锁**：`threading.Lock`。**只包 O(1) 内存复制**（读快照拷贝 / 写快照拷贝），**不持锁做任何 I/O / LLM / TTS**（不阻塞首字）。

**写入规则（S2，闭合）**：
1. **普通成功轮**（LIGHTWEIGHT / RAG / HERMES / DATA 完整成功）→ 覆盖快照：`user_text=本轮文本`、`reply_text=本轮回复`、`route=本轮路由`、`ts=now`。
2. **成功 CONTEXT 轮** → 按普通轮覆盖：`user_text=当前追问文本`、`reply_text=本轮新回复`、`route=延续的 last_route`、`ts=now`（CONTEXT 是真实新的一轮，覆盖语义与普通轮一致）。**含 DATA 无新鲜值诚实降级轮**：延续 `last_route=DATA` 且健康数据不新鲜、返回 `CONTEXT_NO_SNAPSHOT_TEXT` 的轮次**仍属成功 CONTEXT**，按继承的 DATA route 覆盖快照并刷新 ts；该轮既非失败/取消（规则 4），也非无历史 CONTEXT（§1 降级语义），覆盖语义与普通成功 CONTEXT 完全一致。
3. **REPLAY 轮** → **不覆盖**（不写 user_text / reply_text / route，**不刷新 ts**）。重播的是同一回复，「上一轮真实交换」仍是原 user/reply。
4. **失败 / 取消** → **保留旧快照**（写入只发生在成功边界，失败/取消到达不了该边界，天然不覆盖）。
5. **last_route 约束**：仅允许 LIGHTWEIGHT / RAG / HERMES / DATA。`replay` / `context` 是**执行模式/分类标记**，只出现在 `timing` 观测字段，**绝不写入快照 last_route**。

**TTL 刷新**：ts 仅在成功覆盖时刷新（普通轮 / CONTEXT 轮）；REPLAY 不刷新、失败/取消不刷新。

### 3.2 pipeline 会话快照 + replay 执行模式 + 提交（S1/S2，pipeline.py）

- `StreamingPipeline.__init__` 加：`self._last_round: dict | None = None`（键 user_text / reply_text / route / ts）、`self._last_round_lock = threading.Lock()`、`SNAPSHOT_TTL_SECONDS = 600`、`CONTEXT_REPLY_MAX_CHARS = 500`、两个诚实模板常量。
- 提交时点：`_stream_from_text` 主流程 yield 完所有帧、`assistant_parts` 完整拼接后（现有 `extract_memory_async` 附近）写快照；首帧前不触碰。

**REPLAY 执行模式（S1，pipeline 内部独立分支，非只改 timing）**：
- 路由前 `followup_kind = router.classify_followup(text)`；命中 `replay` + 快照有效 → 进入独立 replay 分支：
  - `route = "replay"`（执行模式标记，**不写快照 last_route**）；
  - `selected_llm = None`；`final_text = snapshot.reply_text`；
  - `timing["llm_backend"] = "replay"`；
  - `delta_iter = iter([final_text])`（与 DATA 模板同构：直接分句 + TTS，**零 LLM 调用、零网络**）。
  - 因 `route != HERMES`：`_produce` 内 `if route == HERMES` 安抚语分支**不触发**（不排 HERMES comfort）；`route != HERMES` 触发 TTS 预连接（快速路径）。
  - 该分支**绝不调用 `selected_llm.stream_chat`、绝不读网络**。
- 命中 `replay` + 快照无效 → 本地诚实模板（`final_text = REPLAY_NO_SNAPSHOT_TEXT`，`delta_iter = iter([final_text])`，`llm_backend = "template"`），不调 LLM/网络。

### 3.3 CONTEXT 延续 last_route（S7，逐路由闭合，pipeline.py）

- 命中 `context` + 快照有效 → 构造固定结构上下文前缀，延续 `last_route` 单次调用：

| last_route | 处理 |
|---|---|
| HERMES | `selected_llm = self.llm`，单次 `stream_chat(prefix + text)` |
| LIGHTWEIGHT | `selected_llm = self.lightweight_llm`，单次 `stream_chat(prefix + text)` |
| RAG | **不重新 rag.search、不重新包装【知识库参考】前缀**；单次 `self.lightweight_llm.stream_chat(prefix + text)` |
| DATA | **不送 LLM**（DATA 模板直答本无 LLM）；复用 `_build_health_reply` 重报最新健康数据（若新鲜），否则回 `CONTEXT_NO_SNAPSHOT_TEXT` 诚实降级并**按成功 CONTEXT 覆盖快照**（§2 规则 2） |

- **DATA 诚实降级后覆盖的安全理由**：健康数据不新鲜时若仍保留旧 DATA 快照，后续 REPLAY 会重播已超过 health 新鲜度门（`data_stale_seconds`）的旧心率/血氧，构成误导。因此诚实降级轮按成功 CONTEXT 覆盖快照（reply=降级文本、route=DATA），使后续 REPLAY 重播诚实降级文本而非过期数值——这是**预期行为**，不是缺陷。

- **上下文前缀固定结构**（仅一轮 + 长度上限 + 不写日志）：
  ```
  【上一轮】用户：{last_user_text}
  小V：{last_reply_text[:CONTEXT_REPLY_MAX_CHARS]}

  【本轮】用户：{current_text}
  ```
  - `CONTEXT_REPLY_MAX_CHARS = 500`（截断 reply 防 prompt 膨胀）；
  - 仅上一轮，不叠加多轮；
  - 全文（含前缀、含 reply）**不写日志**（敏感，避免泄露）。
- 命中 `context` + 快照无效 → 本地诚实模板（`final_text = CONTEXT_NO_SNAPSHOT_TEXT`，`delta_iter = iter([final_text])`，`llm_backend = "template"`），不调 LLM/网络。
