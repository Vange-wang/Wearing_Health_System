# BOX-3 音频原理图布局设计 Spec

- 日期：2026-08-19
- 范围：合板原理图中图一所示 ES7210、双麦克风、参考/去耦与音频电源区域
- 参考：图二的模块化排列、留白和文字可读性

## 1. 目标

仅调整原理图布局和导线几何，不改变器件、参数、网络名称或电气连接。首要验收标准是任何元件、位号、参数值、网络名和导线均不互相遮挡。

## 2. 方案选择

采用“受控重排”：保留现有器件和网络，在功能块内部重新放置元件并整理导线。相比只移动文字，该方案能同时解决元件和导线拥挤；相比整块重画，电气连接风险更低。

## 3. 布局结构

1. U1（ES7210）作为中心核心器件。
2. MIC2 链路放在左上，MIC1 链路放在左下，两路结构上下对称。
3. 麦克风耦合、偏置和滤波元件沿信号方向从左到右进入 U1。
4. REF、BIAS、地址及去耦元件按对应引脚在 U1 右侧分行排列。
5. AUD_VDD、稳压和电源滤波电路放在底部独立区域。
6. I2C、I2S、时钟及控制网络按引脚组分层排列，不与模拟输入链路交叉。

## 4. 排版规则

- 所有对象吸附到 0.05 inch 网格。
- 元件外框之间至少保留 30 个原理图坐标单位；功能块之间至少保留 80 个单位。
- 位号、参数值和网络名与元件外框或其他文字至少保留一个网格间距。
- 导线仅使用水平、垂直和直角转折；禁止斜线、穿过元件本体或穿过文字。
- 同组信号平行排列，线间距至少一个网格。
- 长距离连接优先使用网络端口，避免跨越其他功能块。
- 重复且不提供额外信息的网络文字隐藏，但网络属性继续保留。
- 电源标识和地标识放在支路末端，不压住电容、电阻或参数值。

## 5. 电气约束

- 不更改器件型号、位号、参数值和封装关联。
- 不合并不同网络，不拆分现有有效网络。
- ADC_GND 与数字 GND 的现有网络边界保持不变。
- MIC1P/N、MIC2P/N、MICBIAS、REF、I2S、I2C 和 AUD_VDD 网络名称保持不变。

## 6. 验收

1. 目视检查无元件重叠、无文字重叠、无导线穿字或穿元件。
2. MIC1/MIC2 两路结构一眼可辨，信号流向清晰。
3. U1 周边各功能支路分层整齐，网络名可完整阅读。
4. EasyEDA DRC 结果为：致命错误 0、错误 0、警告 0、信息 0。
5. 保存后重新读取原理图源数据，确认器件数量、位号和网络名称未意外丢失。

## 7. 回退与风险控制

重排前保存完整图页源码备份。每完成一个功能块即检查连接状态；若 DRC 或网络审计恶化，恢复到重排前源码并缩小修改范围。
