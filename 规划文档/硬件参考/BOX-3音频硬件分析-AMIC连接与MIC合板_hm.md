## 一、BOX-3 现状：AMIC 板 ↔ 主板连接

### 1.1 连接器

**FPC 排线**（0.5mm 间距，6~8 芯），AMIC 板（双麦子板）插在主板上。

### 1.2 信号线（核心 6 根）

| 信号 | 方向 | 功能 |
|---|---|---|
| ADC_MICBIAS12 | 主板 → AMIC | 麦克风偏置电压（ES7210 Pin11 提供）|
| ADC_MIC1P / MIC1N | AMIC → 主板 | 麦克风 1 差分正/负 |
| ADC_MIC2P / MIC2N | AMIC → 主板 | 麦克风 2 差分正/负 |
| ADC_GND | 双向 | 模拟地（音频地，独立走线）|
| （主板预留 MIC3P/3N）| 扩展 | 第 3 路麦克风备用 |

### 1.3 完整信号链

```
AMIC 板（麦克风子板）                    主板
┌──────────────────────┐   FPC 排线   ┌───────────────────────────┐
│ 2× MEMS 麦克风        │              │                           │
│ (MSM381A3729H9BPC,   │              │  1µF 耦合电容(靠近MIC端)   │
│  差分输出)            │              │                           │
│   VDD←MICBIAS12       │──偏置──────→│  ES7210 Pin11 (MICBIAS12) │
│   OUT+ → MIC1P/2P     │──正───1µF──→│  ES7210 Pin15/13 (MICxP)  │
│   OUT- → MIC1N/2N     │──负───1µF──→│  ES7210 Pin14/12 (MICxN)  │
│   0Ω + 120pF 滤波     │              │  (4通道24bit音频ADC,       │
│   ESD 保护(5颗)       │              │   I2C地址0x40)            │
└──────────────────────┘              │                           │
                                       │  I2S: DOUT→缓冲器→GPIO16  │
                                       │       MCLK→GPIO2          │
                                       │       SCLK→GPIO17         │
                                       │       LRCK→GPIO45         │
                                       │  I2C: SCL→GPIO18, SDA→GPIO8│
                                       │  电源: Aud_VDD→Q1→ES7210  │
                                       └───────────────────────────┘
```

### 1.4 关键设计点（官方设计精华）

1. **差分传输**：麦克风正负两路输出（抗共模干扰）——勿简化成单端
2. **耦合电容"Close to MIC"**：1µF 耦合电容放麦克风端（官方标注要求）
3. **偏置由 ES7210 提供**：MICBIAS12（Pin11）芯片自带，麦克风 VDD 直接接
4. **音频地独立**：ADC_GND 单独走线（不混数字地），整条音频链路都在 ADC_GND 域
5. **静音两级控制**：电源级（Q1 P-MOS 断 ES7210 供电）+ 数据级（三态缓冲器断 I2S）
6. **I2S 缓冲器**：ES7210 输出经 SN74LVC1G126 三态缓冲再进主控（静音高阻，不扰总线）

## 二、MIC 合板方案（自研板：MIC 直接集成主板，不用 FPC）

### 2.1 结论

**完全可行，且更简单**——FPC 是为「子板可插拔/模块化生产」设计的，自研板焊死麦克风更优（少一个连接器、少一段线、可靠性更高）。

### 2.2 集成电路（照抄 + 砍掉）

```
自研主板（MIC 集成版）
┌─────────────────────────────────────────┐
│  2× MEMS 麦克风（直接焊主板）              │
│    VDD ← ES7210 Pin11 (MICBIAS12)       │
│    OUT+ ─1µF(靠近麦克风)─→ ES7210 MICxP  │
│    OUT- ─1µF(靠近麦克风)─→ ES7210 MICxN  │
│    VDD 去耦 10nF + 100pF                 │
│         │                                │
│         ▼                                │
│   ES7210（4ch ADC）→ I2S → 主控          │
│   I2C 控制 + Aud_VDD 供电（照抄）          │
└─────────────────────────────────────────┘
```

| 保留（照抄）| 砍掉（不用）|
|---|---|
| 2 麦差分信号 + 1µF 耦合电容（**靠近麦克风**）| FPC 连接器 |
| MICBIAS 偏置 + 去耦电容 | AMIC 子板 |
| ES7210 周边（参考电压/去耦/Aud_VDD 供电）| 5 颗 ESD（焊死的不需 FPC 插拔保护，可留 1 颗或不装）|
| ADC_GND 音频地独立 | 0Ω 调试跳线（可留可省）|

### 2.3 声学三注意（比电路更关键，画板最易翻车）

1. **外壳开进声孔**：麦克风本体**正对进声孔**（孔径 ~0.5-1mm，别被外壳挡住），孔开在面板上对着麦克风位置
2. **麦克风远离喇叭**：震动/磁场串入会回声自激——至少 2-3cm 距离 + 外壳内隔断（BOX-3 是上下结构：麦克风板在上、喇叭在下）
3. **双麦间距**：影响降噪/波束成形效果，别贴太近（<1cm 效果变差）

### 2.4 代价与收益

- **收益**：板子更小更便宜、可靠性更高（少一个可动部件）、调试简单（免插排线）
- **代价**：麦克风位置焊死，不能灵活换位——自研固定形态（老年人随身设备）无影响

---

## 三、结论

1. BOX-3 音频链路 = 麦克风前端（AMIC 板）+ ES7210 ADC + 缓冲 + I2S 进主控——**无智能芯片在子板**，合板没有技术障碍。
2. 自研板**放心集成**：电路照抄（差分 + 耦合电容位置 + MICBIAS + 音频地）+ 声学三注意（开孔/离喇叭/双麦间距）。
3. 若想更省事：可只做单板集成双麦（不用 FPC/子板/ESD），第一版打板从"主控 + 音频 + 电源"起步（见画板难度分析，音频电源是最易返工部分，预期 1-2 次迭代）。
