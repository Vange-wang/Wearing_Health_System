## 1. 结论

**v0.4 完整闭环，A1~A7 全部落地 + 稳定性/体验项全部收尾。** ESP32-S3-BOX-3 真机「按住说话 → 边录边传（chunked 流式）→ 流式 ASR → 路由 → LLM → edge TTS（并发 + 静音裁剪）→ 帧播放」全链路跑通，用户多轮实测有回复、可打断、句间自然衔接。

## 4. 排障记录（八个关键坑）

### 坑1 · 按键不触发
- 根因：BOX-3 顶部圆键 = **GPIO0 = BSP_BUTTON_CONFIG**（非 GPIO1/MUTE）。
- 修复：MUTE + CONFIG 双注册。

### 坑2 · chunked 上传语义（open write_len）
- 根因：`esp_http_client_open(client, write_len)` 中 `write_len >= 0` 走 Content-Length，`write_len < 0`（即 -1）才走 chunked；且 write 是 raw write，不做自动 chunk 编码。
- 修复：`open(client, -1)` + 手动 chunk 编码（size 十六进制行 + 数据 + CRLF，结束 `0\r\n\r\n`）。

### 坑3 · WiFi 2702 认证失败 reason=2
- 现象：密码正确（PC 保存确认）但 `STA disconnected reason=2`（AUTH_EXPIRE）。
- 修复：显式 `wc.sta.threshold.authmode = WIFI_AUTH_WPA2_PSK` + `wc.sta.channel = 11` + FAST_SCAN；并加 `STA_DISCONNECTED → esp_wifi_connect` 掉线自动重连。

### 坑4 · 服务端奇数 chunk 崩溃
- 现象：`buffer size must be a multiple of element size`（收到 1435 奇数字节）。
- 根因：TCP/chunked 分包可在奇数边界切分 int16 PCM。
- 修复：`_feed` 加 leftover 字节缓存（奇数字节拼接下一 chunk）。

### 坑5 · 「先录音后上传」的流式妥协（已纠正）
- 初版为解决 chunked 坑改成了「先录音到 PSRAM 再 Content-Length 上传」，违背 Spec A2 流式。
- 纠正：恢复真正流式（坑2 方案），边录边传、录音即识别。

### 坑6 · edge 连接复用 Session is closed（已回退）
- 尝试 aiohttp connector 复用 TLS/TCP 省句间握手，但 edge 服务端关闲置连接后复用报 `Session is closed` / `No audio was received` → 502 无反应。
- 回退为每次新建连接（稳定性优先），连续 5 句合成全成功。

### 坑7 · 长回复播放中断（后续帧异常未捕获）
- 现象：长回复多句时，某句 edge 合成失败 → 响应流中断 → 固件读到 EOF → 播放戛然而止（「长句说不完突然停住」）。
- 修复：`body()` 后续帧异常优雅收尾（已播帧照常）+ EdgeTTS 合成加 1 次重试。

### 坑8 · edge 音频自带静音（句间间隔主因）
- 现象：用户反馈「几句话之后间隔一段长时间」。
- 排查证据链：DeepSeek 流式 chunk 到达极快且均匀（122 chunks，首 token 后间隔 0~11ms，3s 吐完）→ **非 LLM 瓶颈**；edge 并发合成稳定（6 句 1.4s）→ **非 TTS 瓶颈**；分析 edge 音频时长 → **前导静音 0.19s + 尾静音 0.57s**，占句间间隔 3/4。
- 修复：`_trim_silence` 裁剪前后静音（峰值 2% 阈值，前后各留 50ms 缓冲）。句间从 ~1.06s 降到 ~0.4s。

## 5. 延迟计量（真机实测，服务端落盘日志）

| 阶段 | 语音 | open_ms | llm_ttft | tts_first | 说明 |
|---|---|---|---|---|---|
| piper 时代（稳态） | 「你刚刚是不是卡住了」 | 989ms | 584 | 198 | 快但音色差 |
| edge + 流式（冷连接） | 「你」 | 2416ms | 1134 | 1175 | 冷启动 |
| edge + 流式 + A7 预热 | 「你好你好你好」 | **1633ms** | **408** | 1111 | ✅ 短句稳态 |
| edge + 流式 + A7（长句） | 「详细介绍一下广东医科」 | 3113ms | 605 | 1157 | 3 句，asr_ms 3012（长音频识别） |

- 短句稳态 open_ms **~1.6s**（A7 预热后），长句 ~3s（ASR 识别长音频的固有耗时 + edge 首句 ~1.1s）。
- **句间间隔**：静音裁剪后从 ~1.06s 降到 **~0.4s**（只剩 A6 300ms 停顿），真机实测自然衔接。
- 剩余瓶颈 = edge 首音频 ~1.1s（Vange「小智音质」决策的固有代价，Spec §9 已接受）。
