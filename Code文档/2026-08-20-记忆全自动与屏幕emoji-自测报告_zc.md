### 3.2 端到端（无信号词自动沉淀，真机链路模拟）

发送无信号词句子「我的单车是捷安特」到 `/api/v1/voice/stream`：

```
HTTP 200, 3.23s
记忆提取新增: [物品] 用户的单车是捷安特   ← user_facts.md 正确落盘
```

**过程中发现并修复一个 bug**：首版提取提示词过严，导致「我的单车是捷安特」被误判 NONE（漏提取）；再前一版提示词过松，导致助手提及但用户未否认的信息被当事实写回（幻觉）。最终版提示词两轮直接对比验证：

| 输入 | 旧提示词 | 最终提示词 |
|---|---|---|
| 用户「我的单车是捷安特」+ 小V「也是好车呀」 | 正确提取 | ✅ 正确提取「用户的单车是捷安特」 |
| 用户「我的单车是捷安特」+ 小V「你之前不是说 FACTOR 吗」 | 幻觉（把 FACTOR 当事实） | ✅ 只提取捷安特，不幻觉 FACTOR |
