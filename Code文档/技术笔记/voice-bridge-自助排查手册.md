# voice-bridge 自助排查手册（用户版）

> 用途：BOX-3 屏幕状态不对 / 语音没反应时，按本手册自查。
> 核心工具：`voice-bridge\fix-voice-bridge.bat`（双击自动诊断 + 修复）。
> 更新：2026-08-20（zcode）

---

## 一、看屏幕 emoji 判断问题

BOX-3 屏幕显示 4 种状态，先看它显示什么，对应排查：

| 屏幕 | 含义 | 说明 |
|---|---|---|
| 😄 大笑 | 一切正常 | 不用管 |
| 🤐 闭嘴 | 语音服务停了 + WiFi 正常 | **跑 fix 脚本**（最常见） |
| 😵 晕乎乎 | 语音服务正常 + WiFi 断了 | 检查手机热点/路由 |
| 🌚 黑脸 | 都不可用 | 先开 WiFi，再跑 fix 脚本 |

---

## 二、最常见的 3 种问题 + 自助解法

### 问题 1：屏幕 🤐（语音服务挂了）— 最常遇到

**原因**：电脑上的 voice-bridge 服务进程崩了/被杀了（热点切换、断电、异常都可能触发）。

**解法**：双击 `voice-bridge\fix-voice-bridge.bat`，它会自动：
1. 检查 8710 端口、mDNS、解析、健康接口
2. 发现异常就杀掉残留进程，重新启动服务
3. 等 15 秒后复查

跑完后等 30 秒，屏幕应该变回 😄。

### 问题 2：屏幕 😵（WiFi 断了）

**原因**：BOX-3 连不上 WiFi（iPhone 热点没开 / 热点换了名字 / 路由器重启）。

**解法**：
1. 确认 iPhone 热点开着（名字是 `v2`）
2. 确认电脑也连在同一个热点 `v2`（右下角 WiFi 图标看）
3. 等 1~2 分钟让 BOX-3 自动重连（固件会自动扫描重连）
4. 还不行就重启一次 BOX-3（拔插 USB 或按 reset 键）

### 问题 3：问天气/新闻没结果，或答「查不了」

**原因**：Clash 代理没开（搜索功能必须走 Clash 7800 端口）。

**解法**：
1. 打开 Clash Verge，确认它在运行
2. 再问一次天气试试

> 注意：DeepSeek 对话、健康问答**不依赖** Clash，只有联网搜索（天气/新闻/股票等）需要它。

## 三、自启动说明

开机时 voice-bridge 会自动启动（登录时）。

如果开机后 BOX-3 是 🤐，可能自启失败，跑一次 fix 脚本即可。

---

## 四、终极排查（脚本都救不回来时）

按顺序做：

| 步骤 | 操作 | 检查点 |
|---|---|---|
| 1 | 重启电脑 | 最简单，一次清掉所有异常进程 |
| 2 | 重启 BOX-3 | 拔插 USB，或按 reset 键 |
| 3 | 确认 iPhone 热点 | 名字必须是 `v2`，手机别锁屏太久（热点会休眠） |
| 4 | 跑 fix 脚本 | `voice-bridge\fix-voice-bridge.bat` |
| 5 | 打开 Clash | 搜索功能需要 |
| 6 | 还是不行 | 把 fix 脚本窗口截图发给开发（窗口里有关键信息） |

---

## 五、给开发的信息（还不行时）

如果以上都试过还不行，把下面信息发给开发：

1. `fix-voice-bridge.bat` 窗口的完整截图（关键）
2. 电脑 WiFi 连的哪个网（`netsh wlan show interfaces`）
3. BOX-3 屏幕显示什么 emoji
4. 最近一次能正常用是什么时候、之后做了什么
