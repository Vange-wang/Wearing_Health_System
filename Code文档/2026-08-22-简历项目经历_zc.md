# 健康便携穿戴与移动终端（毕业设计 · 独立开发）

**时间**：2026.03 – 2026.08　**角色**：架构设计与开发

**项目简介**：设计并实现一套端-边-云协同的健康便携穿戴系统。腕部传感节点实时采集心率/血氧，经 BLE 汇聚至便携式移动终端，终端通过 WiFi 接入大语言模型智能体，实现自然语音的健康咨询、数据查询与异常预警。

**核心工作**：

- **语音桥服务（Python / FastAPI）**：设计可插拔的 ASR / TTS / LLM 抽象接口，实现流式语音流水线——流式 ASR（sherpa-onnx SenseVoice + zipformer 流式转写）→ LLM 流式生成 → 边生成边分句 → 流式 TTS（edge-tts WSS 预连接，与 LLM 生成并行），将「用户开口到听到首字」的首字延迟压缩至 **1800ms**。
- **首字延迟优化**：TTS 预连接、8 并发合成 worker + 序号重排、句间停顿调度、慢路径安抚语先行等多级策略，在保证低延迟前提下支持工具调用（联网搜索）等慢路径场景。
- **检索增强（RAG）**：构建健康知识库，jieba 分词 + 自实现 BM25 关键词检索（numpy 向量化），零重依赖起步，检索耗时约 **15ms**，不牺牲首字延迟。
- **多路由智能体**：实现慢路径（Hermes 工具调用）/ 轻量通道（DeepSeek 直连）/ RAG 知识问答 / 健康数据模板直答四条路由，按意图自动分流。
- **嵌入式传感节点（ESP32-C3 + MAX30102）**：编写 MAX30102 软件 I2C（bit-bang）驱动，规避硬件 I2C 驱动在设备 NACK 时的看门狗饿死问题；实现心率（峰峰间隔法）与血氧（R 比率拟合）算法；BLE 外设广播心率 + 血氧自定义综合帧。
- **便携式移动终端固件（ESP32-S3）**：mDNS 服务发现、语音采集与播放、按键交互、状态表情显示、异常阈值预警（心率/血氧连续超限告警）。

**技术栈**：Python 3.11 · FastAPI · sherpa-onnx · edge-tts · DeepSeek API · ESP-IDF（C）· BLE · NimBLE · FreeRTOS

**成果**：

- 打通端-边-云完整链路，流式语音交互首字延迟 1800ms，BLE 广播/GATT 服务手机扫描验证通过（RSSI -42）
- 落地 BLE 数据帧协议（8 字节综合帧），心率/血氧算法实现并完成固件级验证
- 知识库 RAG 检索 15ms，实现「心率/血氧/睡眠」等健康主题的即时问答
