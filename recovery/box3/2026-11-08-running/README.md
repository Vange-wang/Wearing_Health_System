# BOX3 与语音桥回退点（2026-11-08）

板上应用头 288 字节与 manifest 指向的本机 6ac21fbb 固件逐字节一致。固件代码位于 firmware/main。精确恢复使用 manifest 中校验通过的本机工厂应用镜像。公开仓库保留源码和哈希。构建依赖包括 ESP-IDF 5.2.7、外部 ESP-BOX 组件及 esp-sr；从全新环境重建出相同二进制尚未验证。

voice-bridge 记录电脑端正在运行的搜索试用版本，当时健康接口返回 web_search_enabled=true。首问冲突、唤醒和首字延迟仍在真机验收。恢复时在独立检出中使用原主机的凭据、模型、运行依赖与个人配置。voice_v2.web_search 设为 false 并重启语音服务可关闭新搜索路径；回退其他代码需要检出对应提交。未刷入设备的尾音候选不在本快照内。
