# 唤醒与上传恢复候选

源基线为 `box3-before-mic-boot-20261110` 的 11-10 固件。基础目录完整复制，仅覆盖 `main/voice_agent.c` 和 `main/voice_v2_runtime.inc`。镜像和源码校验值见 manifest.json。

此候选处理唤醒绑定后就绪撤销卡住，以及上传或回复失败后仍重新显示监听。成功回复、句中续说和打断在主机夹具中检查。原固件保持安装状态，此目录中的版本尚未刷入设备。

审查结论为有限真机试验准入。续说链空答行为、打断诊断、连续真实播放以及首字延迟仍待核对；不能据此认定冷启动和复杂收音已解决。丢失输入没有自动恢复。

当前构建使用本机 SDK 基底和覆盖对象，干净检出重建尚未完成。配置、SDK和本机镜像需按项目既有方式配置。不要将此归档作为已发布固件部署入口。

后续验收与发现见 GitHub Issues #1、#2、#3、#4。声学断句和增益实验没有纳入此候选。
