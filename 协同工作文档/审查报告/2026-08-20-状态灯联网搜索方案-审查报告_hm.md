## 三、需求 3 追加（用户要求：「box3 端的东西也必须纳入记忆系统」）

**触发背景（2026-08-20 实测）**：用户语音告知小V「英文名 Vange」，次日问「还记得我叫什么名字吗」→ 小V忘记。根因查证（llm.py）：语音对话默认走 lightweight（DeepSeek 裸模型），信息只存在于内存 deque（8 条 / 600s TTL / 重启即丢），USER.md 为只读注入且不含语音新说的信息——**语音记忆从未落盘**。

**方案（已写入 Spec §3.3，分层闭环）**：
1. 持久层：新增 `voice-bridge/memory/user_facts.md`（§ 分隔条目、去重、≤100 条/8KB 裁剪）；不写回 Hermes USER.md（字符上限 1375 + Hermes 侧管理，避免越权冲突）；
2. 提取层：回复完成后后台异步调 DeepSeek 做记忆提取（`REMEMBER: 类别: 事实` / `NONE`），信号词触发 + 轻量保底，不阻塞回复；
3. 注入层：`_system_prompt()` 在 USER.md 后追加 user_facts.md 内容；
4. 同步增强（本期不做）：Hermes 侧定期 review 合并入主记忆，留 ISSUE。

**验收标准**（Spec §四 需求 3，5 条）：10 分钟 TTL 后答对 / 重启后答对（落盘）/ 去重 / 提取失败不影响回复 / 称呼不再遗忘。
