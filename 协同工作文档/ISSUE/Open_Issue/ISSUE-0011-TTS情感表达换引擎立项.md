## 描述

edge-tts 7.2.8 官方移除了自定义 SSML 支持（「Custom SSML support was removed because Microsoft prevents the use of any SSML that could not be generated by Microsoft Edge itself」），`mstts:express-as` 情感风格不可行（`Communicate` 内部把标签转义成正文）。

两轮调优后（第一轮人设+语速，第二轮 SSML 失败回滚），edge-tts 的情感表达已到上限——音色自然、发音标准，但韵律仍是「中性播报腔」偏多，达不到「像真人闲聊」的情绪起伏。

## 选型结论（2026-08-19 更新：回退 edge，云 TTS 后续）

**CosyVoice 本地实测不可行**（zcode 部署承接报告 `2026-08-19-CosyVoice部署承接报告_zc.md`）：
- 硬件实为 **RTX 3050 Laptop 4GB**（非 Spec 所写 8G），CosyVoice2-0.5B 实测 **RTF 8.3**（合成 5.6s 音频需 46s，首包 35~46s），无法实时语音。
- 已排除 load_jit/fp16 优化（实测无效），瓶颈 = 0.5B LLM 自回归 + 算力弱，是硬件硬限制。
- **Vange 拍板（2026-08-19）：回退 edge-tts**（当前已优化，tts_first 均值 383ms，稳定可用）。
