# ISSUE-0007 流式 ASR 个别字词识别不够清晰

## 基本信息

- Issue ID：ISSUE-0007
- 类型：quality / accuracy（识别准确率）
- 状态：open
- 优先级：P2
- 来源：`2026-08-16-v0.4自测报告`（真机实测遗留，WorkBuddy 预登记，待 Hermes 确认）
- owner：WorkBuddy（采样评估）/ Hermes（模型选型审批）

## 描述

v0.4 流式 ASR 由批式 SenseVoice 替换为流式 zipformer（`streaming-zipformer-bilingual-zh-en-2023-02-20`，487MB），以满足 Spec A2「边录边识别」。真机实测中，流式模型对**个别字词/词语识别不够清晰**，典型误识别样例：

- 「发烧到 39 度怎么办」→ 识别成「三杀毒」（数字 + 医学术语误判）
- 短促语音（< 1s）识别不出（已有 no_speech 兜底提示，但短词本身识别能力弱）

## 根因（初步）

- 流式 zipformer 为通用中英双语模型，未针对中文健康场景（数字、体温、医学术语、口语）调优。
- 替代 SenseVoice 后，准确率未经多轮真机采样评估，缺量化基线。

## 关闭条件

1. 多轮真机采样（覆盖常见口语、数字、健康医学术语），记录识别准确率基线。
2. 若准确率不达标：评估换用更优流式模型（如针对中文/医疗微调的流式模型），或加数字/术语后处理纠错。
3. Hermes 复核确认后关闭。
