# ISSUE-0010 会话级路由记忆（指代追问延续慢路径）

## 基本信息

- Issue ID：ISSUE-0010
- 类型：feature / routing（路由层多轮记忆）
- 状态：open
- 优先级：P2
- 来源：`2026-08-16-实时查询能力缺口-确认.md`（Hermes 第二轮登记）
- owner：WorkBuddy（实现）/ Hermes（方案审批）

## 描述

多轮指代追问中，追问句不命中 `tool_keywords` → 路由跌回轻量通道（DeepSeek 裸模型）→ 无搜索能力 → **编造实时数据**。典型样例：

- 「帮我查一下东莞的天气」（命中「帮我查」→ 慢路径 Hermes，真联网查）→ 「深圳的呢」（不命中关键词 → 轻量通道 DeepSeek → 编造深圳天气）。

## 根因

路由判定**每轮独立**（只匹配本轮文本关键词），缺**会话级记忆**：上轮是查询类（慢路径）时，本轮指代追问应延续慢路径，但当前没有这个延续逻辑。

与 ISSUE-0008 不同层：0008 解决「轻量通道内部」的多轮指代（滑动窗口历史），本项是「路由层」——指代追问应延续慢路径而非跌回轻量。

## 关闭条件

1. 路由层加会话级记忆：上轮 route=hermes 时，本轮指代追问（无明确新意图、未命中其他关键词）延续慢路径。
2. 端到端验证：「帮我查东莞天气」→「深圳的呢」连续两轮，第二轮仍走慢路径且真联网查询（非编造）。
3. Hermes 复核确认后关闭。

## 处理记录

- 2026-08-16：由 Hermes 第二轮确认登记为 open（P2，编造实时数据的直接根因）。
- 2026-08-16（实现）：`app/router.py` 加会话级路由记忆——`Router._last_route` 记住上一轮路由；`route()` 在「上轮 hermes + 本轮是短追问」时延续慢路径。`_is_followup()`：短句（≤10 字）且①含追问词（呢/那/这/也/还有等）或②不含新话题信号（动词/疑问结构）→ 判定为延续。**鲁棒处理 ASR 丢轻声词**（「深圳的呢」→ASR 识别「深圳的」，靠反向信号兜底仍判延续）。单测 7 场景全对，端到端「帮我查东莞天气→深圳的呢」两轮均 route=hermes，29 passed。
