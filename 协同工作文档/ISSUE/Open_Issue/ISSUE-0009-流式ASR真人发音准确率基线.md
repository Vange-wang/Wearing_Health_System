# ISSUE-0009 流式 ASR 真人发音准确率基线

## 基本信息

- Issue ID：ISSUE-0009
- 类型：accuracy baseline（准确率基线评估）
- 状态：open
- 优先级：P3
- 来源：ISSUE-0007 关闭时拆出（`2026-08-16-ISSUE-0007-0008-复核报告.md`）
- owner：WorkBuddy（采样评估）

## 描述

ISSUE-0007 的尾截断 bug 已修复（标准发音 15/15），但真人发音（带口音/口语）的识别准确率尚未采样评估。这是 zipformer 流式模型的**能力持续评估**（非 bug），需建立真人发音准确率基线。

## 待办

真人发音真机采样 15 句（带口音/口语，覆盖数字、健康医学术语），对比识别结果，记录准确率基线。

## 关闭条件

真人发音采样评估完成，记录准确率基线；若准确率明显偏低，评估热词表 / 换模型 / 后处理纠错，Hermes 复核后关闭。

## 处理记录

- 2026-08-16：由 ISSUE-0007 关闭时拆出，登记为 open（P3，模型能力持续评估）。
- 2026-08-16（真机采样，Vange 真人发音，服务端日志 vb-v04.log 留证）：15 句结果——**完全一致 11/15；近义可接受 2/15（头疼→头痛、嗓子疼→嗓子痛）；硬错误 2/15（体温→气温、烧到→收到）**；另有 3 句首次识别错/空、重说才对（心率一百二十→情侣一百二十三块、血压一百二八十→一百二十八丢「十」、头晕首次 0 字）。
  - 错误模式：①医学术语（心率 xīn lǜ → 情侣 qíng lǚ）②同音字（体温 tǐ wēn → 气温 qì wēn；烧到 → 收到）③数字连读丢字（一百二八十 → 一百二十八）。
  - **结论：真人发音准确率显著低于离线标准发音 15/15，通用 zipformer 未针对中文健康场景/口语调优，印证 ISSUE-0007 拆出本项的必要性。**
- **待办**：① 记录准确率基线后 Hermes 复核；② 若准确率判定偏低，评估热词表 / 换模型 / 数字术语后处理纠错（需 Hermes 选型审批）。
