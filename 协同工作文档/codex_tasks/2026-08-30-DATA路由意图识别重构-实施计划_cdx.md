# DATA 路由意图识别重构实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. 本计划由 Codex 在当前会话内串行执行，不分派子代理；每项用复核检查点收口。

**Goal:** 让确定性的当前健康数值查询继续走 DATA 模板直答，让健康知识、原因、方法、关系和选购问题进入 lightweight/RAG；同时让白名单外的健康数据问法只引用新鲜实测值，数据缺失或过期时绝不编造。

**Architecture:** Router 只保留窄查询短语的确定性 DATA 拦截，并在 DATA 前应用知识类排除词；未命中 DATA 的健康领域句在 RAG 判定后直接进入 lightweight，避免被通用“看看/是什么”等工具词送去 Hermes。`StreamingPipeline` 继续持有 `HealthDataStore`，向 `LightweightLLM` 绑定一个只读、内存级健康上下文提供器；`LightweightLLM` 仅对含心率/心跳/血氧的健康问题追加新鲜数据，普通闲聊不增加提示词长度。

**Tech Stack:** Python 3.11、FastAPI、pytest、现有 `Router` / `StreamingPipeline` / `LightweightLLM` / `HealthDataStore`，DeepSeek 直连，BOX-3 COM5 与腕带健康数据上报。

**Spec:** `协同工作文档/codex_tasks/2026-08-30-DATA路由意图识别重构-任务单_hm.md`

**Review:** `协同工作文档/审查报告/2026-08-30-DATA路由意图识别重构任务单-审查意见_zc.md`

def _is_health_domain(self, text: str) -> bool:

def _is_data_query(self, text: str) -> bool:

```python
def _build_lightweight_health_context(self) -> str | None:
    if self.health is None:
        return None
    latest = self.health.get_latest_fields()
    parts = []
    if latest.hr is not None and latest.hr_age_s is not None and latest.hr_age_s <= self.data_stale_seconds:
        parts.append(f"心率 {int(round(latest.hr))}（{int(round(latest.hr_age_s))}秒前）")
    if latest.spo2 is not None and latest.spo2_age_s is not None and latest.spo2_age_s <= self.data_stale_seconds:
        parts.append(f"血氧 {int(round(latest.spo2))}（{int(round(latest.spo2_age_s))}秒前）")
    if not parts:
        return None
    return "当前健康数据（仅可引用以下新鲜实测值）：" + "，".join(parts) + "。"
```
