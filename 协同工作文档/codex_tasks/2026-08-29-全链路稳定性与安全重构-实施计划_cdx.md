# 可穿戴健康辅助系统全链路稳定性与安全重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** 在保持现有 BLE、HTTP、按键和 WAV 外部协议兼容的前提下，完成两套固件、voice-bridge、告警链路和构建归档的整体稳定性与安全重构。

**Architecture:** 腕带拆分为传感器驱动、样本缓冲、P1 算法、质量门和 BLE 输出；BOX-3 拆分为凭据、网络、BLE、音频会话和告警客户端；voice-bridge 拆分为设备认证、健康数据、持久化告警、微信发送和请求级语音会话。每个批次先形成失败证据，再完成最小实现和独立验收。

**Tech Stack:** ESP-IDF 5.2.7、ESP32-C3、ESP32-S3 BOX-3、C、Python 3.11、FastAPI、pytest、NimBLE、NVS、HTTP chunked、edge-tts。

**Spec:** 规划文档/Spec文档/2026-08-29-全链路稳定性与安全重构-spec_cdx.md
