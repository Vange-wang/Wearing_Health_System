## 接线（文档确认）

```
ESP32-C3 3V3 ── VIN    ESP32-C3 GND ── GND
GPIO4(SDA)  ── SDA    GPIO5(SCL)  ── SCL
GPIO2(可选)  ── INT
```

## 实施内容

1. **ESP-IDF 工程**：`ble_wrist_node/`（或现有 ble_scan 改造，zcode 定），idf v5.2.7；
2. **MAX30102 驱动**：I2C 0x57，配置 LED 电流/采样率，FIFO 读取 + 血氧/心率算法（标准峰峰间隔法即可，P1 指尖式验证，与指尖血氧仪对比 ±3%）；
3. **BLE peripheral**：按 `2026-08-19-BLE数据帧协议_zc.md` 的 GATT 布局 + 8 字节综合帧（每 5s 一帧）；
4. **状态指示**：GPIO8 RGB（连接上 BOX-3 后变绿/呼吸，未连接红色）；
5. **低功耗**：P1 不做深度休眠（Spec 预留），但采样间隙 light sleep 可选。

## 验收（P1，Spec §6）

1. 腕部节点 BLE 发出心率/血氧（指尖式验证，与指尖血氧仪对比**误差 ±3% 内**）；
2. GATT 帧格式与协议文档一致（8 字节综合帧，5s/帧）；
3. `esptool --port COM6 flash` 烧录成功 + 日志无 fatal；
4. 送 Hermes 审查（代码 + 实测数据）。
