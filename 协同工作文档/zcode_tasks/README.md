# zcode_tasks — Hermes 下达任务单目录（2026-08-21 建立）

> **用途**：存放 Hermes（审查方）下达给 zcode（开发方）的**任务单**与**对齐告知**。
> **与 zcode_handoff 的区别**：`zcode_handoff/` 只放 zcode 自己的**线程交接文档**（`YYYY-MM-DD-交接-线程N_zc.md`）；本目录放 Hermes 写给 zcode 的**任务派发**（`_hm` 后缀）。

## 目录分工

| 目录 | 内容 | 产出方 | 后缀 |
|---|---|---|---|
| `协同工作文档/zcode_tasks/` | 任务单（需求/缺陷/改造指令） | Hermes | `_hm` |
| `协同工作文档/zcode_handoff/` | zcode 线程交接文档 | zcode | `_zc` |

## 使用流程

1. **Hermes 下达**：任务单写入本目录，命名 `YYYY-MM-DD-<主题>-任务单_hm.md`；
2. **zcode 执行**：读最新任务单 → 实施 → 产出完成报告（`协同工作文档/YYYY-MM-DD-<主题>-完成报告_zc.md`）→ 送 Hermes 审查；
3. **闭环**：Hermes 审查 → 报告落盘 `审查报告/` → 任务单可标记完成或归档。
