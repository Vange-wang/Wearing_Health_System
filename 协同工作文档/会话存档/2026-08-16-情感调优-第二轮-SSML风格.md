## 一、诊断

「机器人味」的根源不在文本和语速，而在 **edge-tts 默认用「neutral 中性风格」合成**——这是微软的默认语音风格，语调是规整的「新闻播报腔」：每个字时长均匀、重音中规中矩、没有情绪起伏。音色再自然，也摆脱不了「念稿」感。

**解法**：用 SSML 的 `mstts:express-as` 标签，把说话风格从 neutral 切成 **chat（聊天对话）** 或 **affectionate（亲切温暖）**。这是微软为「对话场景」专门调教的韵律模型，语调有起伏、有停顿、有情绪，是「像真人」的关键一步。

---

## 二、修改方案（app/tts.py）

edge-tts 的 `Communicate` 第一参数直接传 **SSML 字符串**（替换原来的纯文本）：

```python
import edge_tts

SSML_TEMPLATE = '''<speak version="1.0" xmlns="http://www.w3.org/2001/10/synthesis" xmlns:mstts="https://www.w3.org/2001/mstts" xml:lang="zh-CN">
<voice name="{voice}">
<mstts:express-as style="{style}" styledegree="1.3">
{text}
</mstts:express-as>
</voice>
</speak>'''

def build_ssml(text: str, style: str = "chat", voice: str = "zh-CN-XiaoxiaoNeural") -> str:
    # XML 转义，防止 & < > 破坏 SSML
    text = text.replace("&", "&amp;").replace("<", "&lt;").replace(">", "&gt;")
    return SSML_TEMPLATE.format(voice=voice, style=style, text=text)

# 合成时：
ssml = build_ssml(sentence, style="chat")
communicate = edge_tts.Communicate(ssml, voice="zh-CN-XiaoxiaoNeural", rate="-5%", volume="+0%", pitch="+0Hz")
```

## 三、风格选择（实测对比，选最自然的）

| style | 效果 | 适用 |
|---|---|---|
| **chat** | 聊天对话腔，语调随和、有起伏，最像真人闲聊 | **首选** |
| **affectionate** | 亲切温暖腔，带关心和温度 | 健康助手「关心用户」场景，可对比 |
| cheerful | 愉快欢乐腔，偏活泼 | 人设「活泼幽默」可试 |
| assistant | 智能助手腔，比 neutral 自然但更「专业」 | 备选 |

建议：先测 **chat** 和 **affectionate** 两个，同一句话对比，选最「像朋友」的。`styledegree` 默认 1，想更明显调 `1.3~1.5`（别到 2，会夸张）。

---

## 四、配合微调（可选，叠加用）

1. 语速：`rate="-5%"` 保持；若 chat 风格本身偏慢，回调 `-3%`。
2. 停顿：`mstts:silence` 可精确控制标点停顿时长（如逗号 80ms、句号 120ms），比「句间 300ms」更细腻，可后续替换 pipeline 的固定停顿。

---

## 五、验收

1. 同一句话「你今天过得怎么样呀～」：neutral 风格 vs chat 风格，chat 明显有情绪起伏、更像真人。
2. 语音完整对话一轮，人耳判断「机器人味」是否明显下降。
3. 确认 XML 转义正确（含 `&`、`<` 的文本不报错、不合成错乱）。

---

## 六、注意事项

- **SSML 与流式首帧兼容**：style 只改变合成内容（语调），不影响 mp3 分段解码的流式机制，之前方案 2 的 edge 流式首帧照常工作。
- **XML 转义必须做**：LLM 生成的文本可能含 `&`、`<`，不转义会破坏 SSML 导致合成失败。
- 若 chat 风格实测仍不够「真人」，说明 edge-tts 到上限了，下一步是换引擎（CosyVoice / 火山口语化音色 / GPT-SoVITS 克隆），先别急着换，chat 风格大概率够用。
