# zcode 任务单：单一记忆源改造（voice-bridge 侧，v2）

- **下达方**：Hermes（审查）· 2026-08-20 · 依据 Vange 拍板方案 v2
- **方案依据**：`规划文档/技术验证/2026-08-20-单一记忆源-三端共享方案_hm.md`（v2 定稿）
- **状态**：待 zcode 实施（Hermes 侧 memory_server 并行开发中）
- **核心目标**：三端共享记忆（写入即见）+ BOX-3 首字延迟零牺牲

## 架构（v2：单一共享记忆，无独立快速层）

```
Hermes 记忆（唯一正本）：USER.md（画像）+ MEMORY.md（事实，容量 8000）
  ├ BOX-3 注入：本地读 USER.md 全文 + MEMORY.md 最近部分，合计 ≤6KB（量恒定）
  ├ 手机/电脑/微信：Hermes 原有机制注入全量（与 BOX-3 首字无关）
  ├ 提取：voice-bridge 后台调 POST /api/v1/memory/fact → 写 MEMORY.md（写入即共享）
  └ 遗忘：后台调 DELETE /api/v1/memory/fact?keyword= → 字段级删 USER.md + MEMORY.md（全端失效）
```

## 改动要求

### 1. `voice-bridge/app/memory.py`：MemoryStore → MemoryClient（HTTP）

1. **MemoryClient**（对 `http://127.0.0.1:8781/api/v1/memory`）：
   - `add_fact(category, fact, keywords)` → POST /fact（写 MEMORY.md，Hermes 侧去重）；
   - `remove_by_keyword(keyword)` → DELETE /fact?keyword=（字段级删除 USER.md + MEMORY.md）；
   - `load_recent(budget_bytes=6144)` → GET /memory + 本地截取最近 6KB（供注入）；
   - 失败静默（不阻断语音回复）+ 重试 1 次 + 日志。
2. **删除**：`MemoryStore` 文件读写逻辑移除；`voice-bridge/memory/` 目录（user_facts.md + .gitignore）废弃，待存量迁移后清理。

### 2. `voice-bridge/app/llm.py`：注入 + 提取 + 遗忘

1. **注入**（`_system_prompt`）：USER.md（本地直读，红线保留）+ **MEMORY.md 最近部分（≤6KB 总预算）**——替代现读 user_facts.md；读取失败 USER.md 仍抛错降级（红线不变），MEMORY.md 失败静默跳过；
2. **提取**（`extract_memory_async`）：REMEMBER 解析后调 `MemoryClient.add_fact`（不再写本地文件）；
3. **遗忘**（FORGET 分支）：调 `MemoryClient.remove_by_keyword`（删全端）。

### 3. `voice-bridge/app/config.py`

新增 `memory_api_url`（默认 `http://127.0.0.1:8781/api/v1/memory`）+ `memory_inject_budget`（默认 6144）。

### 4. 存量迁移（配合 Hermes）

现有 `memory/user_facts.md` 2 条（单车/学校）：Hermes 侧迁移进 MEMORY.md → 确认后**删除 `voice-bridge/memory/` 目录**。

### 5. 测试

- `tests/test_memory_auto.py`：mock MemoryClient（不依赖真实 Hermes）：写入调用 / 6KB 截取 / 失败静默 / 遗忘调用；
- 回归：全量 `pytest tests/` 通过（现 60 passed）。

## 首字红线（验收硬条款）

- **注入只读本地文件（USER.md + MEMORY.md 本地路径），绝不在首字路径发起 HTTP**；
- 改造前后各测 10 次「你好」llm_ttft，均值差 ≤ +50ms；
- 提取/遗忘全在回复完成后后台线程。

## 验收（三端共享，写入即见）

1. 语音「我喜欢蓝色」→ **不等待归档**，电脑/微信问 Hermes「用户喜欢什么颜色」→ 立即答出；
2. 电脑端 Hermes 记忆「生日 2005.09.19」→ BOX-3 语音问「我生日」→ 答出（注入窗口含该条）；
3. 语音「忘掉我的英文名」→ USER.md 字段级删（名字/生日/电话保留）+ MEMORY.md 删 → 两端都不再答出；
4. 首字：改造前后 llm_ttft 对比 ≤ +50ms；
5. 回归：全量单测通过。
