# zcode 会话交接规范

> 对齐 WorkBuddy（WB_handoff）与 Hermes（Hermes_handoff）的交接机制。
> 目的：zcode 线程/会话上下文将满（或用户指示）时，产出交接文档，新线程读最新文档即可开工。

## 一、触发时机

1. Vange 说「线程太满」「交接」「换线程」时；
2. zcode 自身检测到上下文将满时；
3. 一段大任务完成后主动交接（可选）。

## 二、交接三步

1. **总结**：按下方模板总结当前状态。
2. **存盘**：写入本目录（`协同工作文档/zcode_handoff/`），命名 `YYYY-MM-DD-交接-线程N_zc.md`。一交接一文档，**不覆盖**旧文档。
3. **开工**：新线程读**最新一份**交接文档即可恢复上下文。

## 三、模板字段

| 字段 | 说明 |
|---|---|
| 一句话现状 | 当前任务处于什么状态 |
| 已完成（本线程）| 本线程内做过的关键事项 |
| 未完成（带优先级）| 剩余事项 + P1/P2/P3 |
| 阻塞点 | 卡在哪（硬件未到/等某人/外部依赖）|
| 关键文件（绝对路径）| 下一步要用的文件路径 |
| 下一步动作 | 新线程开工第一件事 |
| 规范提醒 | agent.md 关键条款（后缀/审查/模型守卫）|

## 四、注意

- 交接文档是「状态快照」，写清**下一步能直接开工**的信息即可。
- 文件后缀 `_zc`（agent.md §5.1）。
