## 背景

Hermes 侧 memory_server 已实现字段级删除：事实段 `身高: 175cm; 体重: 55kg` 中，忘「身高」只删该对、保留体重。**前提是提取层把事实写成 `属性: 值` 结构**——当前 voice-bridge 提取层（llm.py）输出的是叙述句（如「用户的单车是FACTOR OSTRO VAM」「身高一米七五」），非结构化。

## 改动要求（voice-bridge/app/llm.py 提取提示词 + 解析）

1. **提取提示词**：REMEMBER 行要求输出结构化 `属性: 值` 形态——
   ```
   REMEMBER: <类别>: <属性>: <值>
   ```
   示例：`REMEMBER: 身体: 身高: 175cm` / `REMEMBER: 物品: 单车: FACTOR OSTRO VAM`
   - 同一轮多个属性 → 合并到同一类别多行（`身体: 身高: 175cm` + `身体: 体重: 55kg`）；
   - 无法拆成属性-值的事实（叙述性，如「用户是广东医科大学的学生」）→ 允许整句（memory_server 对无属性结构走整段删除兜底）；
2. **解析层**：`REMEMBER: 类别: 属性: 值` 三段解析（现有正则支持 `类别: 事实`，需扩展为可选三段）；`fact` 字段传给 memory_server 时**带属性名**（`身高: 175cm`），keyword 含属性名 + 值；
3. **关键词规则**：属性名 + 值都进关键词（`身高,175cm`），供遗忘关联词清理。

## 验收

1. 语音「我的身高是175cm」→ MEMORY.md 落盘为 `身体 | 身高: 175cm | 身高,175cm`；
2. 语音「忘掉我的身高」→ 字段级删除，同段其他属性（如有）保留；
3. 叙述性事实（学校/单车）→ 仍正常落盘（整句形态）；
4. 回归：全量单测通过（现 61 passed）+ 既有遗忘/去重验收不回退。
