# 国外搜索链路延迟优化 完成报告（73s → 搜索 3.3s）

- **执行方**：Hermes（deepseek-v4-pro）· 2026-08-20
- **对象**：voice-bridge 慢路径（Hermes 联网搜索）延迟
- **结论**：**优化完成，已达目标（搜索 3.3s ≤ 5s，实测 9.8s 全链路）**。根因是「国外搜索 API 直连被墙导致超时重试」，已通过选择性代理解决。Vange 拍板维持 Tavily，不切换 DDG。

---

## 一、根因（已实测定位）

| 项 | 证据 |
|---|---|
| 搜索后端是国外服务 | Hermes 内置 5 个后端（Firecrawl/SearXNG/Parallel/Tavily/Exa）全是国外服务 |
| gateway 清空代理变量 | `Hermes_Gateway.vbs:11-12` 原为 `HTTP_PROXY="" / HTTPS_PROXY=""`（保 DeepSeek/iLink 直连） |
| 直连被墙 | 实测：Tavily 直连 10.5s 超时；DDG 直连 10s 超时（http=000）；走代理 0.7s/0.66s |
| 73s 构成 | Hermes agent 调 Tavily → 直连超时 → 重试多次 → tool_ms=69.3s |

## 二、优化措施（已生效）

1. **`Hermes_Gateway.vbs` 选择性代理**（已备份 .bak-20260820_174316）：
   - `HTTP_PROXY/HTTPS_PROXY/ALL_PROXY = http://127.0.0.1:7800`（Clash）
   - `NO_PROXY` 白名单：`localhost,127.0.0.1,::1,*.local,api.deepseek.com,ilinkai.weixin.qq.com,.weixin.qq.com,.qq.com,内网段` → **DeepSeek/iLink 保持直连**
2. gateway 重启生效（PID 36424，17:44）。

## 三、实测数据

| 指标 | 优化前 | 优化后 |
|---|---|---|
| Tavily 搜索（tool_ms） | 69.3s（重试） | **3.3s**（走代理） |
| 完整链路（问天气→回答） | 73s | **9.8s**（实测 18:13，广州天气返回真实结果） |
