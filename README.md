# 可穿戴健康辅助系统

ESP32-C3 传感节点通过 BLE 向 ESP32-S3-BOX-3 汇聚健康数据，BOX3 经 WiFi 接入电脑语音服务，完成语音识别、聊天、联网搜索和语音回复。

## 运行链路与状态

语音链路为 BOX3收音 → v2上传 → 本机SenseVoice（sherpa-onnx）识别 → 普通聊天、天气或网页搜索 → Edge TTS → 音频与字幕 → BOX3播放回执。具体模型、路由和供应商以配置为准。

搜索字幕区小恐龙及“正在搜索...”已有用户实机确认。冷启动间歇漏唤醒、侧向轻声和停顿识别、上传失败后的恢复仍在处理，见 Issues #1–#3。双BLE节点使用同一腕部协议，当前健康接口选择一个有效来源上报；独立胸部固件与双用户独立查询尚未确认实现。

本次复跑的搜索、时效性、网页路由、v2回执和音频输入29项测试通过。11月11日更广的152项选定测试中149通过、3项失败，契约问题记录在[测试摘要](Code文档/测试报告/2026-11-11-项目摸底测试摘要.md)与Issue #4。

## 构建与使用

电脑服务依赖和配置见 [voice-bridge说明](voice-bridge/README.md)。BOX3当前构建仍依赖本机ESP-IDF 5.2.7、ESP-BOX组件及历史构建基底，干净检出重建尚待验证。固件说明列出源与镜像的对应关系。

`.work/` 保存本机SDK、模型、构建和实验。凭据、私人数据及固件镜像保留本机。部署前按 [AGENTS.md](AGENTS.md) 核对回退点与验收范围。首字延迟是项目最高约束。
