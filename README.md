# 可穿戴健康辅助系统

毕业设计项目：ESP32 传感节点（BLE）→ ESP32-S3 语音终端（WiFi）→ Hermes 智能体（DeepSeek）的语音交互健康辅助系统。

## 当前阶段

截至 2026-11-11，项目处于语音桥、BOX3 与双 BLE 节点的集成及可靠性验证阶段。语音交互和搜索动画已有实机记录，冷启动唤醒、复杂场景收声及连续会话仍待验收。

当前运行源码保存在回退标签 `box3-before-mic-boot-20261110`。主分支的业务代码较早，请先阅读[项目现状与版本导航](Code文档/项目现状-2026-11-11.md)，其中列出源代码入口、候选、测试结果及 GitHub 问题。
